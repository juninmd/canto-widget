Το Canto προσφέρει **42 γλώσσες διεπαφής**, η καθεμία με το δικό της README. Επιλέξτε τη δική σας στις **Ρυθμίσεις → Γλώσσα**.
το εργαλείο επιλογής με δυνατότητα αναζήτησης χρησιμοποιεί ονόματα εγγενών γλωσσών και η αυτόματη λειτουργία ακολουθεί την κύρια γλώσσα του συστήματός σας.
Τα αραβικά, τα εβραϊκά και τα περσικά χρησιμοποιούν κείμενο από δεξιά προς τα αριστερά. Πρόσθετοι κατάλογοι γλωσσών φορτώνονται κατ' απαίτηση.

Οι 40 νέοι κατάλογοι διεπαφής και οι 31 νέες μεταφράσεις README είναι μηχανικές μεταφράσεις και δεν έχουν γίνει
αξιολογήθηκε από φυσικούς ομιλητές. Τα πορτογαλικά και τα αγγλικά παραμένουν οι αρχικοί κατάλογοι διεπαφής. Ετικέτες δίσκου και
Οι επικεφαλίδες ειδοποιήσεων ακολουθούν την επιλεγμένη γλώσσα. ορισμένες λεπτομέρειες ειδοποίησης ενσωμάτωσης επιστρέφουν στα Αγγλικά,
και τα σφάλματα backend παραμένουν στα πορτογαλικά. Η σύνταξη τίτλου εργασίας διατηρεί τις υπάρχουσες λέξεις-κλειδιά στα Πορτογαλικά και τα Αγγλικά.

🌙 **Μην ενοχλείτε:** στις Ρυθμίσεις ή στο δίσκο, σίγαση ειδοποιήσεων συσκέψεων, υπενθυμίσεις εργασιών, ειδοποιήσεις κατάστασης και κάθε

όταν τελειώνει? ένα κλικ το απενεργοποιεί ξανά. Επιβιώνει από μια επανεκκίνηση και τελειώνει μόνο του.

🔔 **Κάθε ειδοποίηση σε μία οθόνη:** το κουδούνι στην κεφαλίδα (μέτρηση και χρώμα όταν οτιδήποτε εκκρεμεί) ανοίγει το
ειδοποιήσεις σε όλο το παράθυρο σε οποιαδήποτε λειτουργία: μία κάρτα ανά ειδοποίηση με τις ενέργειές της, **παράβλεψη όλων** και τι ήταν
επιλύθηκε σήμερα βάσει αυτών — χωρίς να υπάρχει τίποτα σε εκκρεμότητα, έτσι θα φτάσετε ακόμα στο σημερινό αρχείο καταγραφής. Από την αποβάθρα, ένα κλικ
εξακολουθεί να ανοίγει αυτή τη μοναδική ειδοποίηση πάνω από το κανονικό παράθυρο.

⌨️ **Τα πάντα με πληκτρολόγιο:** `Alt+1`…`Alt+7` εναλλαγή καρτελών, `N` δημιουργία, `/` αναζητήσεις, `F11` σε πλήρη οθόνη, `Alt+L`
κλειδώνει και `?` παραθέτει τις συντομεύσεις. `Ctrl+Shift+P` (`Cmd+Shift+P` σε macOS) ανοίγει μια **παλέτα εντολών** με κάθε
ενέργεια με βάση το όνομα: μετάβαση σε μια καρτέλα, νέα εργασία ή σημείωση, συμμετοχή στην επόμενη συνάντηση, αντιγραφή της σύνοψης της ημέρας, αλλαγή δέρματος, κλείδωμα.

δεν μπορεί να αναφέρει το εστιασμένο παράθυρο, επομένως παραμένει μη διαθέσιμο εκεί). Απενεργοποιήστε μέχρι να δηλώσετε συμμετοχή στην πρώτη οθόνη

- **Ημέρα**: ένα ντόνατ ανά κατηγορία με το σύνολο μέσα, του οποίου ο μύθος κρύβει μια κατηγορία, η αλλαγή με την ημέρα
πριν και τον χρόνο αδράνειας (χωρίς πληκτρολόγιο ή ποντίκι για 2 λεπτά). Κάτω από αυτό, ένας καθημερινός στόχος εστίασης κώδικα με το σερί του και
μία κουκκίδα την ημέρα, τρία highlights (μεγαλύτερη έκταση σε μία εφαρμογή, διακόπτες εφαρμογών, ώρα αιχμής), ένα χρονοδιάγραμμα όπου το σύνολο
ημέρα, η αδράνεια εκτείνεται και οι πιο πολυσύχναστες εφαρμογές μοιράζονται έναν άξονα χρόνου με έναν δείκτη "τώρα" και μια λίστα εφαρμογών
(πατήστε ένα για να αλλάξετε την κατηγορία του) ή από τις εργασίες στις οποίες έτρεξε το χρονόμετρο εστίασης.
- **Εβδομάδα**: στοιβαγμένες στήλες ανά ημέρα με τη μέση γραμμή και μια κουκκίδα κάτω από κάθε ημέρα που πέτυχε τον στόχο, χάρτης θερμότητας μιας ώρας
με την αιχμή σας, και τις ίδιες λίστες για όλη την εβδομάδα.
- **Διάταξη και επιφάνειες**: μία στήλη στο προεπιλεγμένο παράθυρο, δύο όταν είναι φαρδύ (μεγιστοποιημένη). κάθε δέρμα έχει το δικό του
χρώματα κατηγορίας, ελεγμένο για αντίθεση. Το μενού δίπλα στην ημέρα το αντιγράφει ως κείμενο.

<sub>✅ εγγενές · ➖ μερικό, μέσω επέκτασης ή προαιρετικό · — κανένα · ? μη δημοσιευμένο · n/a δεν αποθηκεύει δεδομένα χρήστη</sub>

Τι έφερε εδώ το σημείο αναφοράς: **ώρα ακριβώς στον τίτλο της εργασίας** (Todoist/TickTick), **αναβολή της ειδοποίησης**
(TickTick) και **πρόχειρο που σέβεται τους διαχειριστές κωδικών πρόσβασης** (CopyQ/Ditto).

## ⬇️ Εγκατάσταση

Κατεβάστε το πρόγραμμα εγκατάστασης για την πλατφόρμα σας από **[Releases](https://github.com/juninmd/canto-widget/releases)**:

| Σύστημα | Αρχείο |
|---|---|
| 🪟 Windows 10/11 | `Canto_x.y.z_x64-setup.exe` (συνιστάται) ή `.msi` |
| 🍎 macOS | `.dmg` για Apple Silicon ή Intel |
| 🐧 Linux | `.AppImage`, `.deb` ή `.rpm` |

1. Κατά την πρώτη εκτέλεση δημιουργείτε τον **κύριο κωδικό πρόσβασης**. Δεν υπάρχει ανάκτηση: χάσετε τον κωδικό πρόσβασης, χάσετε τα δεδομένα.
2. `Ctrl+Alt+Space` (`Cmd+Shift+Space` σε macOS) εμφανίζει και αποκρύπτει το γραφικό στοιχείο.
3. Έγινε. Όταν αποστέλλεται μια νέα έκδοση, το Canto σάς ειδοποιεί και οι **Ρυθμίσεις → Ενημερώσεις** ενημερώνονται με ένα κλικ.

> [!ΣΗΜΕΙΩΣΗ]
> Τα προγράμματα εγκατάστασης δεν έχουν υπογραφεί ακόμη με κωδικό: το SmartScreen (Windows) και το Gatekeeper (macOS) προειδοποιούν κατά την πρώτη εκκίνηση.
> Οι αυτόματες ενημερώσεις επαληθεύονται με την υπογραφή του ίδιου του έργου πριν από την εκτέλεση.

Έτοιμα μανιφέστα για το winget και το Homebrew (συν ένας σκελετός για το Flatpak, προς το παρόν αποκλεισμένο) ζωντανά στο
[`packaging/`](packaging/README.md) — προετοιμάστηκε και επαληθεύτηκε τοπικά, αλλά δεν έχει ακόμη δημοσιευθεί σε αυτούς
αποθετήρια: η δημοσίευση είναι μια χειροκίνητη απόφαση και ενέργεια του συντηρητή.

## 🔒 Ασφάλεια με μια ματιά

| Στρώμα | Προστασία |
|---|---|
| Θόλος | Argon2id (19 MiB, t=2) → AES-256-GCM, ένα νέο nonce σε κάθε εγγραφή, ατομική εγγραφή με `fsync` |
| Κλειδί | Μόνο RAM, μηδενισμένη στο κλείδωμα. ρυθμιζόμενο αυτόματο κλείδωμα (5 έως 60 λεπτά σε αδράνεια, 15 λεπτά από προεπιλογή) |
| Δίκτυο | Μόνο η διαδικασία Rust μιλάει στο δίκτυο. η προβολή ιστού δεν έχει απομακρυσμένη προέλευση (CSP) και δεν βλέπει ποτέ διακριτικά |
| Google | προαιρετικό, μόνο `calendar.events.readonly`, `directory.readonly` (φωτογραφίες συναδέλφων του χώρου εργασίας στη λίστα προσκεκλημένων) συν προφίλ, OAuth με PKCE και loopback |
| GitHub | προαιρετικό, κρυπτογραφημένο διακριτικό. τα στοιχεία ανοίγουν μόνο εάν ο σύνδεσμος είναι `https://github.com/` |
| GitLab | προαιρετική, κρυπτογραφημένη διεύθυνση και διακριτικό. Μόνο `https://`, χωρίς ανακατευθύνσεις, συνδέσεις μόνο από τη διαμορφωμένη παρουσία |
| Ενημερώσεις | Εγκαθιστά μόνο ένα πακέτο υπογεγραμμένο από το κλειδί του έργου. μια παραποιημένη λήψη απορρίπτεται πριν από την εκτέλεση |

Πλήρες μοντέλο, δημιουργία αντιγράφων ασφαλείας, συγχώνευση μεταξύ των μηχανημάτων και όπου ζει κάθε αρχείο: [docs/seguranca.md](docs/seguranca.md).

## 🛠️ Ανάπτυξη

Προαπαιτούμενα: [Bun](https://bun.sh) ≥ 1,2, σταθερό Rust ≥ 1,85 και το
[Tauri v2 dependencies](https://v2.tauri.app/start/prerequisites/) για το σύστημά σας.

```bash
bun install
bun run tauri dev                                        # app with hot reload
bun run lint && bun test                                 # types and UI tests
bun run build && cd src-tauri && cargo clippy --all-targets -- -D warnings && cargo test
bun run tauri build                                      # installer for the current platform
```

Οι προβολές ιστού δημιουργούνται μετά την κατάσταση Rust και την προετοιμασία του δίσκου, επομένως οι κλήσεις IPC εκκίνησης δεν μπορούν να δρομολογηθούν.

Κάθε PR εκτελεί CI σε Windows, macOS και Linux. Τα συμβατικά `fix`, `feat` και breaking commit συγχωνεύτηκαν σε `main`
λάβετε μια ετικέτα SemVer, δημιουργήθηκαν σημειώσεις έκδοσης και υπογεγραμμένα προγράμματα εγκατάστασης που έχουν κατασκευαστεί παράλληλα. η έκδοση δημοσιεύεται μετά από επαλήθευση (λεπτομέρειες στο
[CONTRIBUTING.md](CONTRIBUTING.md#publicar-uma-versão)).
