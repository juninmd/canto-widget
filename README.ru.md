> **Задачи с напоминаниями, заметки, история буфера обмена, повестка дня с оповещениями о встречах, транскрипты
> и ваши PR на GitHub в небольшом окне, закреплённом в углу экрана.** Появляется по `Ctrl+Alt+Space`, скрывается,
> когда не нужна, и хранит всё в зашифрованном виде на вашей машине — без аккаунта и без сервера.

## ✨ Зачем Canto

<table>
<tr>
<td width="44%" align="center"><img src="docs/prints/readme/tour.gif" alt="Обзор вкладок «Задачи», «Заметки», «Буфер обмена», «Повестка дня» и «GitHub», оповещение о встрече и скины" width="300"></td>
<td>

Если вы живёте между встречами, PR и мелкими незакрытыми делами, у вас в итоге открыто пять приложений. Canto
собирает всё это в одном месте.

🔒 **Зашифровано по умолчанию.** Argon2id + AES-256-GCM с мастер-паролем; ключ существует только в оперативной
памяти. Windows Hello опционально.

🏠 **Ваши данные остаются у вас.** Ноль телеметрии, ноль сервера, аккаунт не нужен. Резервная копия — это один
зашифрованный файл `.canto`.

⏰ **Вы не пропустите.** За 1 минуту до встречи и в момент напоминания виджет всплывает, воспроизводит звук и
отправляет уведомление, с **отложить на 10 мин**.

🪶 **Лёгкое.** Tauri v2 (Rust + системный webview) вместо Electron: установщик весом 3,5 МБ.
[Измеренные показатели](docs/benchmark.md#footprint-medido).

🔄 **Всегда актуально.** Обновления прямо из приложения, устанавливается только то, что подписано собственным
ключом проекта.

</td>
</tr>
</table>

### 🐙 Ваш GitHub в одном взгляде

**Запрошено ревью у меня**, назначено мне, PR и issue, открытые мной, с иконкой PR или issue и указанием, кто
их открыл. Фильтр по тексту, `repo:` или `label:`, только PR или только issue, сортировка по обновлению,
созданию или комментариям, прокрутка через **показать ещё**. Также поддерживает **GitLab.com и
self-hosted GitLab**, с кешем на 5 минут, уважающим лимит запросов. Вход по личному токену только для чтения
или из браузера (device flow).

Также есть 🎙️ **Встречи**: заметки Gemini и транскрипты за последние две недели, а также транскрипты `.vtt`,
`.srt`, `.txt` и `.md` из локальной папки — очищенные и доступные для поиска.

⌨️ **Всё с клавиатуры:** `Alt+1`…`Alt+7` переключают вкладки, `N` создаёт, `/` ищет, `F11` полноэкранный режим,
`Alt+L` блокирует, а `?` показывает список сочетаний клавиш.

| MeetingBar | — | — | — | ✅ | — | н/д |

<sub>✅ встроено · ➖ частично, через расширение или опционально · — отсутствует · ? не опубликовано · н/д не хранит пользовательские данные</sub>

оповещение** (TickTick) и **буфер обмена, уважающий менеджеры паролей** (CopyQ/Ditto).

## ⬇️ Установка

Скачайте установщик для вашей платформы со страницы **[Releases](https://github.com/juninmd/canto-widget/releases)**:

| Система | Файл |
|---|---|
| 🪟 Windows 10/11 | `Canto_x.y.z_x64-setup.exe` (рекомендуется) или `.msi` |
| 🍎 macOS | `.dmg` для Apple Silicon или Intel |
| 🐧 Linux | `.AppImage`, `.deb` или `.rpm` |

1. При первом запуске вы создаёте **мастер-пароль**. Восстановления нет: потеряете пароль — потеряете данные.
2. `Ctrl+Alt+Space` (`Cmd+Shift+Space` на macOS) показывает и скрывает виджет.
3. Готово. Когда выходит новая версия, Canto уведомляет вас, а **Настройки → Обновления** обновляются в один клик.

> [!NOTE]
> Установщики пока не имеют цифровой подписи кода: SmartScreen (Windows) и Gatekeeper (macOS) предупреждают
> при первом запуске. Автоматические обновления проверяются по собственной подписи проекта перед запуском.

Готовые манифесты для winget и Homebrew (а также заготовка для Flatpak, пока заблокированная) лежат в
[`packaging/`](packaging/README.md) — подготовлены и проверены локально, но ещё не опубликованы в этих
репозиториях: публикация — это ручное решение и действие сопровождающего.

## 🔒 Безопасность вкратце

| Уровень | Защита |
|---|---|
| Хранилище | Argon2id (19 МиБ, t=2) → AES-256-GCM, новый nonce при каждой записи, атомарная запись с `fsync` |
| Ключ | только в оперативной памяти, обнуляется при блокировке; настраиваемая автоблокировка (от 5 до 60 минут простоя, по умолчанию 15 минут) |
| Сеть | с сетью общается только процесс Rust; у webview нет удалённого источника (CSP), и он никогда не видит токены |
| Google | опционально, только `calendar.events.readonly` и профиль, OAuth с PKCE и loopback |
| GitHub | опционально, зашифрованный токен; элементы открываются, только если ссылка `https://github.com/` |
| GitLab | опционально, зашифрованные адрес и токен; только `https://`, без редиректов, ссылки только с настроенного инстанса |
| Обновления | устанавливается только пакет, подписанный ключом проекта; подделанная загрузка отбрасывается до запуска |

Полная модель, резервное копирование, слияние между машинами и расположение файлов:
[docs/seguranca.md](docs/seguranca.md). Нашли уязвимость? [SECURITY.md](SECURITY.md).

## 🛠️ Разработка

Требования: [Bun](https://bun.sh) ≥ 1.2, стабильный Rust ≥ 1.85 и
[зависимости Tauri v2](https://v2.tauri.app/start/prerequisites/) для вашей системы.

```bash
bun install
bun run tauri dev                                        # приложение с hot reload
bun run lint && bun test                                 # типы и UI-тесты
bun run build && cd src-tauri && cargo clippy --all-targets -- -D warnings && cargo test
bun run tauri build                                      # установщик для текущей платформы
```

Каждый PR запускает CI на Windows, macOS и Linux. Тег `v*` собирает подписанные установщики для обновлений в
черновом релизе (пошагово в [CONTRIBUTING.md](CONTRIBUTING.md#publicar-uma-versão)).
