### ✅ உங்களுக்கு நினைவூட்டும் பணிகள்

நேரம் மற்றும் மறுநிகழ்வு கொண்ட தினசரி சரிபார்ப்பு பட்டியல் (ஒவ்வொரு நாளும், வார நாட்கள் அல்லது வாரந்தோறும்). வகை **`Daily at 9:30am`** மற்றும் தி
நினைவூட்டல் ஏற்கனவே அமைக்கப்பட்டுள்ளது; முன்னுரிமைக்காக **`!high`** (அல்லது `!alta`, `!média`, `!baixa`) சேர்க்கவும் அல்லது அதைச் சுழற்சி செய்ய வரிசையில் உள்ள புள்ளியைக் கிளிக் செய்யவும். துண்டிக்கப்படுவதற்குப் பதிலாக நீண்ட தலைப்புகள் மூடப்பட்டிருக்கும். எந்தப் பணியிலும் **ஃபோகஸ் டைமரை**: மதிப்பீட்டைக் கொடுக்கவும், ▶ஐ அழுத்தவும், மேலும் ஒவ்வொரு தாவலின் கீழும் பின் செய்யப்பட்ட பட்டை அதற்கு எதிரான நேரத்தைக் கணக்கிடும் (நீங்கள் சென்றவுடன் சிவப்பு); ஒவ்வொரு நிமிடமும் பெட்டகத்திற்கு நேரம் சேமிக்கப்படுகிறது. **நாள் சுருக்கம்** ஒட்டுவதற்குத் தயாராக உள்ளது (பணிகள், கவனம் செலுத்திய நேரம், மொத்த நேரத்துடன் கூடிய சந்திப்புகள், PRs/MRs திறக்கப்பட்டது, ஒன்றிணைக்கப்பட்டது, மதிப்பாய்வு செய்யப்பட்டது மற்றும் இணைக்கப்படாமல் மூடப்பட்டது), மார்க் டவுனில் **வாராந்திர மற்றும் மாதாந்திர அறிக்கை**, மற்றும் **நிலுவையில் உள்ள பொருட்களை இழுக்க** நேற்றிலிருந்து. **விரைவான பிடிப்பு** (`Ctrl+Alt+N`, `Ctrl+Cmd+N` macOS இல்) விட்ஜெட்டைத் திறக்காமலேயே எந்த பயன்பாட்டிலிருந்தும் ஒரு பணி அல்லது குறிப்பை எழுதுகிறது.

### 📅 கூட்டம் தொடங்குகிறதா? அது உங்களுக்கு சொல்கிறது.

`Ctrl+Alt+Shift+M` (`Ctrl+Cmd+Shift+M` macOS இல்); இரண்டும் கிடைக்கவில்லை என்றால் தட்டு மெனு தொடர்ந்து இருக்கும்.

இன்றைய நிகழ்வுகள் Google காலெண்டரிலிருந்து வந்தவை (படிக்க மட்டும்). ஒரு நிமிடத்திற்கு முன், விட்ஜெட் திரையில் தாவுகிறது

ஒவ்வொரு அட்டையும் உங்கள் பதிலுடன் ஒரு பேட்ஜைக் காட்டுகிறது (ஏற்றுக்கொள்ளப்பட்டது, ஒருவேளை, நிராகரிக்கப்பட்டது, காத்திருக்கிறது). யார் ஏற்பாடு செய்தார்கள் என்பதைப் பார்க்க நிகழ்வைக் கிளிக் செய்யவும்
அது, நிகழ்ச்சி நிரல், ஒவ்வொரு விருந்தினருக்கும் இனிஷியல் அவதாரம் மற்றும் அவற்றின் பதில் மற்றும் இணைப்புகள், ஜெமினியின் குறிப்புகள் போன்றவை.
குறைந்தபட்சம் 15 நிமிடங்களுக்கு **அடுத்த இலவச ஸ்லாட்டை** மேல் வரி உங்களுக்குக் கூறுகிறது (நிராகரிக்கப்பட்ட அழைப்புகள் மற்றும் அனைத்து நாள் நிகழ்வுகள் இல்லை
எண்ணிக்கை), மற்றும் ஒன்றுடன் ஒன்று நடக்கும் நிகழ்வுகள் மற்ற நிகழ்வுக்கு பெயரிடும் **மோதல்** பேட்ஜைப் பெறுகின்றன. **இன்று** பார்வையானது மீட்டிங் நடந்துகொண்டிருக்கும் (மீட்டிங், சேரும் பொத்தான், மோதல் எச்சரிக்கை) அல்லது அடுத்தது, பிறகு **ஒரு வரியில் நாள்** (கூட்டங்கள், பணிகள் மற்றும் வேலை நேரம் முழுவதும் ஓய்வு நேரம், சந்திப்பு நேரம், இலவச நேரம் மற்றும் மோதல்கள் கணக்கிடப்படும்) மற்றும் ஒரு காலவரிசை, கூட்டங்கள், நேரத்துடன் கூடிய பணிகள் மற்றும் இலவச இடைவெளிகள் ஏற்கனவே தங்களுக்கு ஏற்ற பணிகளின் வரிசைகளாக உள்ளன. தொலைவில்.

பூட்டுகள் மற்றும் `?` குறுக்குவழிகளை பட்டியலிடுகிறது. `Ctrl+Shift+P` (macOS இல் `Cmd+Shift+P`) ஒரு **கட்டளை தட்டு** ஒவ்வொன்றிலும் திறக்கிறது
பெயரின்படி செயல்: ஒரு தாவலுக்குச் செல்லவும், புதிய பணி அல்லது குறிப்பு, அடுத்த சந்திப்பில் சேரவும், அன்றைய சுருக்கத்தை நகலெடுக்கவும், தோலை மாற்றவும், பூட்டவும்.

**செயல்பாடு** தாவல் மறைக்கப்படத் தொடங்குகிறது (அமைப்புகள் → தெரியும் தாவல்களின் கீழ் அதை இயக்கவும்). என்ற பெயரை மட்டுமே பதிவு செய்கிறது
நீங்கள் கணினியைப் பயன்படுத்தும் போது, ஒரு சீல் செய்யப்பட்ட உள்ளூர் கோப்பில், காப்புப்பிரதிகள் அல்லது ஒத்திசைவுகள் (வேலண்ட்) அடையாது.
ஃபோகஸ் செய்யப்பட்ட சாளரத்தைப் புகாரளிக்க முடியாது, எனவே அது அங்கு கிடைக்காமல் இருக்கும்). நீங்கள் தேர்வு செய்யும் வரை ஆஃப், மற்றும் முதல் திரை என்ன சொல்லும்
வைக்கப்பட்டுள்ளது மற்றும் எப்போதும் இல்லாதது.

- **நாள்**: மொத்த உட்புறத்துடன் வகை வாரியாக ஒரு டோனட், அதன் புராணக்கதை ஒரு வகையை மறைக்கிறது, நாளுக்கு எதிரான மாற்றம்
முன் மற்றும் செயலற்ற நேரம் (2 நிமிடங்களுக்கு விசைப்பலகை அல்லது மவுஸ் இல்லை). அதற்குக் கீழே, தினசரி குறியீட்டு-கவனம் இலக்கை அதன் ஸ்ட்ரீக் மற்றும்
ஒரு நாளைக்கு ஒரு புள்ளி, மூன்று சிறப்பம்சங்கள் (ஒரு பயன்பாட்டில் மிக நீளமான நீட்டிப்பு, ஆப்ஸ் சுவிட்சுகள், பீக் ஹவர்), ஒரு காலவரிசை முழுவதும்
நாள், செயலற்ற நிலைகள் மற்றும் பரபரப்பான பயன்பாடுகள் "இப்போது" மார்க்கருடன் ஒரு நேர அச்சைப் பகிர்ந்து கொள்கின்றன மற்றும் பயன்பாடுகளின் பட்டியலுடன்
(அதன் வகையை மாற்ற ஒன்றைத் தட்டவும்) அல்லது ஃபோகஸ் டைமர் இயக்கிய பணிகளில்.
- **வாரம்**: சராசரி கோட்டுடன் ஒரு நாளைக்கு அடுக்கப்பட்ட நெடுவரிசைகள் மற்றும் இலக்கை எட்டிய ஒவ்வொரு நாளின் கீழும் ஒரு புள்ளி, ஒரு மணிநேர வெப்ப வரைபடம்
உங்கள் உச்சம், மற்றும் வாரம் முழுவதும் ஒரே பட்டியல்கள்.
- **தளவமைப்பு மற்றும் தோல்கள்**: இயல்புநிலை சாளரத்தில் ஒரு நெடுவரிசை, இரண்டு முறை அகலமானது (அதிகப்படுத்தப்பட்டது); ஒவ்வொரு தோல் அதன் சொந்த உள்ளது
வகை வண்ணங்கள், மாறுபாட்டிற்காக சரிபார்க்கப்பட்டது. நாளுக்கு அடுத்துள்ள மெனு அதை உரையாக நகலெடுக்கிறது.

## 🛠️ வளர்ச்சி

முன்நிபந்தனைகள்: [Bun](https://bun.sh) ≥ 1.2, நிலையான Rust ≥ 1.85 மற்றும்
உங்கள் கணினிக்கான [Tauri v2 dependencies](https://v2.tauri.app/start/prerequisites/).

```bash
bun install
bun run tauri dev                                        # app with hot reload
bun run lint && bun test                                 # types and UI tests
bun run build && cd src-tauri && cargo clippy --all-targets -- -D warnings && cargo test
bun run tauri build                                      # installer for the current platform
```

வெப்வியூக்கள் Rust நிலைக்குப் பிறகு உருவாக்கப்பட்டு, தட்டு துவக்கப்படும், எனவே தொடக்க IPC அழைப்புகள் ரேஸ் அமைப்பை அமைக்க முடியாது.

ஒவ்வொரு PR Windows, macOS மற்றும் Linux இல் CI ஐ இயக்குகிறது. வழக்கமான `fix`, `feat` மற்றும் பிரேக்கிங் கமிட்கள் `main` இல் இணைக்கப்பட்டன
SemVer டேக், உருவாக்கப்பட்ட வெளியீட்டு குறிப்புகள் மற்றும் இணையாக கட்டப்பட்ட கையொப்பமிடப்பட்ட நிறுவிகளைப் பெறுங்கள்; சரிபார்ப்புக்குப் பிறகு வெளியீடு வெளியிடப்படுகிறது (விவரங்கள்
[CONTRIBUTING.md](CONTRIBUTING.md#publicar-uma-versão)).
